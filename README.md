
# Анализ сроков доставки и их влияние на клиентский опыт

Данные бразильского маркетплейса Olist: ~100 тысяч заказов за 2016–2018 годы.

## Что сделано

Разобрался, как соблюдение сроков доставки влияет на оценки покупателей. Нашёл регионы, где опоздания случаются чаще всего, и прикинул, сколько это стоит бизнесу.

## Как устроен проект

1. Загрузил данные в PostgreSQL — четыре таблицы: заказы, клиенты, отзывы и платежи
2. Проверил дубликаты, пропуски, типы — данные почти чистые, можно работать
3. Разбил заказы на две группы: доставленные вовремя и с опозданием
4. Сравнил средние оценки
5. Посмотрел на ситуацию по штатам, наложил на карту выручки — нашёл проблемные точки

## Главные цифры

- **6.8%** заказов опаздывают — примерно каждый пятнадцатый
- Оценка падает с **4.3 до 2.3** — клиенты такого не прощают
- Самые проблемные штаты — **RJ** (12.1% опозданий) и **BA** (12.2%), оба в топе по выручке

## Что с этим делать

Пересмотреть логистику в RJ и BA, снизить опоздания до средних 6–8%, это напрямую поднимет рейтинг площадки и вернёт часть клиентов за повторными покупками.

## Стек

Python, Pandas, PostgreSQL, SQLAlchemy, Matplotlib, Superset

## Данные

Датасет Brazilian E-Commerce Public Dataset by Olist на Kaggle:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
